# Auto-approve work schedule

勤務表の承認作業を自動化するChrome拡張機能です。拡張機能アイコンをクリックすることで、日次承認処理を自動実行します。

## 機能概要

- 日次勤務表の自動承認処理（現在の承認ボタンを全件処理）
- 各承認のモーダル確認を自動クリック
- エラーが発生した場合も処理を継続し、完了後に成功・失敗件数を表示

### 将来対応予定
- ユーザー入力時間とシステム記録時間の差分チェック（15分以上の差異がある場合は警告）
- 時間差異がある場合のコメント確認機能

## インストール方法

1. このリポジトリをクローンまたはダウンロード
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」を有効化
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このリポジトリのフォルダを選択

## 使い方

1. 勤務表の承認画面を開く
2. Chrome拡張機能アイコンをクリック
3. ポップアップの「承認処理開始」ボタンをクリック
4. 処理が完了するまで待機
5. 完了後、承認結果のレポートが表示されます

## 対象システムの仕様

### ページ構成
- **日次ページ**: 日付ごとの勤務タスク詳細を表示。承認ボタンはこのページにのみ存在
- **月次ページ**: 当月の勤務時間を一覧表示。ユーザー入力とシステム記録の2種類を表示

### 申請タイプ
- 予定申請: 事前の勤務予定
- 実績申請: 実際の勤務記録
- ※実績申請後は予定申請不可

### 時間記録
- **ユーザー入力時間**: 従業員が手動で入力した開始・終了時間
- **システム記録時間**: システムが自動記録した開始・終了時間（記録がない場合は非表示）

## 開発

### 必要な環境
- Chrome browser (バージョン88以降推奨)
- Manifest V3対応

### ファイル構成

```
chrome-extension-approval/
├── manifest.json   # Manifest V3 設定
├── popup.html      # 拡張機能のポップアップ UI
├── popup.js        # ポップアップのボタン制御・スクリプト注入
├── utils.js        # 共通ユーティリティ（sleep / waitForElement / waitForModalClose）
├── content.js      # 承認処理のメインロジック
└── README.md
```
